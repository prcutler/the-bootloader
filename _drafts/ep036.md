Paul

By now I'm guessing most folks have heard that our favorite CircuitPython code editor, Mu, was sunset back in December of 2024. We've seen a couple of really strong online editors since then and now we have a spiritual successor to Mu called RV Circuit Studio. 

Created by Armstrong Subero, RV Circuit Studio is a full featured CircuitPython IDE itself written in Python. It has so many nice touches, I'll probably forget a few, but the first time you start it up it asks you where you want to backup your code.py - which is so nice. And then when you plug in a board it will detect whether it's running the latest version of CircuitPython and open the download page to your board to help you.

The first thing you might want to do is make the text size a bit bigger depending on your screen - you can do that right from the Settings toggle in the main window bar.

I've got an rp2040 Feather with a DPS310 sensor plugged in right now. You can see my `code.py` in the editor on the right and the file explorer is on the left. Along the bottom is the REPL and it's currently printing out the Pressure readings from the sensor. 

It also makes todbot's SerialPlotster obsolete, and has a really nice plotter built in.  Here you can see it plotting my pressure readings.

And here might be my favorite feature - in the left hand sidebar are a ton of code snippets organized by type. I don't know about you, but I learn a lot by cobbling together different bits of code, and here it puts a ton of examples right at your fingertips. From debouncing to PWM to battery voltage monitor, Armstrong has included a ton of examples to help folks get started.

It is a Python app available on Windows, macOS, and Linux. But it's not a native app, so you'll need to use the built-in menu bar. Eveything in the UI has a toggle, so you can hide or show the project explorer, snippets, etc. It has a debugger built in and you can step through functions, like you would find in most modern IDEs.  You can also reformat your code using the Black linter, and it will prompt you to first install it if you need to.

And last, one of my favorite features, the Library manager. It will show you what's installed and if there is an update avaiable. Just hit the other tab to browse through all the available libraries from the official bundle. I couldn't figure out how to add the Community Library to it, but I'm guessing I'm just missing something.

My hat's off to Armstrong Subero - thanks for creating RV Circuit Studio. When someone asks for an editor recommendation, this is now my goto for CircuitPython. It runs locally and has install packages for macOS, Windows, and Linux. It does the all the major things you would expect, but there are so many nice touches from the code backup to the snippets to the library manager to using `black` for code formatting, I could go on.
